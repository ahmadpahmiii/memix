# Chip

Pill-shaped filter chips for categories in Templates and Sounds.

- **Provide:** a short label (one or two words) and a selected state.
- **Use:** single-select category filters in a horizontally scrolling row with `space-3` gaps.
- **Selected:** `selection` (white) fill with `on-primary` text, as in CapCut. Unselected: `surface-raised` with `text`. No borders.
- **Don't:** use chips as buttons that trigger actions; use them inside the editors.
