# BottomNav

The app's five-item bottom navigation: Home, Templates, Create, Sounds, Drafts.

- **Provide:** the current destination.
- **Create** sits in the middle as a `primary` block (`radius-md`, plus icon in `on-primary`); it opens the Create sheet (Video meme or Photo meme) instead of navigating.
- **Current item:** `text` label and icon. Others: `text-secondary`. Blue is reserved for Create, so the bar has one accent.
- **Hidden** inside both editors and the export flow.
