# SegmentedTabs

A two- or three-way switch, used for the Video / Photo choice in Templates. (Drafts is one list sorted by last edit, with a type badge per row: P1-14.)

- **Provide:** two or three labels and the selected one.
- **Use:** switching between parallel views of the same screen. For more than three options, use Tabs.
- **Selected:** `surface-raised` pill with `text` inside a `canvas` track. Unselected: `text-secondary`.
- **Large text** (P2-04 review: es "Filtros", "Ajustes", "Deep-fry" cut to "Filtr…" at 200%): a label is never truncated. When the equal-width tabs don't fit, the tabs size to their labels and the row scrolls sideways, each label whole on one line, the selected tab scrolled into view.
