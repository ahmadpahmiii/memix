# SegmentedTabs

A two- or three-way switch, used for the Video / Photo choice in Templates and Drafts.

- **Provide:** two or three labels and the selected one.
- **Use:** switching between parallel views of the same screen. For more than three options, use Tabs.
- **Selected:** `surface-raised` pill with `text` inside a `canvas` track. Unselected: `text-secondary`.
