# ToolBar

The bottom tool bar in both editors: a horizontally scrolling row of icon-plus-label tools.

- **Provide:** the tool list for the current editor and selection, and the active tool.
- **Video editor tools:** Edit, Audio, Meme sounds, Text, Stickers, Effects, Filters, Overlay, Remove BG, Speed, Ratio.
- **Photo editor tools:** Formats, Text, Stickers, Draw, Adjust, Filters, Remove BG, Censor, Crop.
- **Active tool:** `primary` icon and label on a `primary-subtle` `radius-md` highlight. Others: `text-secondary`.
- **Layout:** `surface` bar, `toolbar-height`, `hairline` top border, 64-wide items at least `touch-target` tall. No outlines or shadows.
