# ToolBar

The bottom tool bar in both editors: a horizontally scrolling row of icon-plus-label tools.

- **Provide:** the tool list for the current editor and selection, and the active tool.
- **Video editor tools (nothing selected), each added with its ticket, in this final order:**
  - Edit
  - Meme sounds (P1-08)
  - Text (P1-10)
  - Add media (P1-16): adds videos or photos after the clip under the playhead
  - Overlay (P4-01b, icon `overlay`): opens the picker for one video or photo to place on top of the main video; not shown in an empty project. Fifth, next to Add media (its sibling), so Voiceover is sixth (spec `docs/ux/specs/P4-01b-overlay-layers.md`)
  - Voiceover (P3-08, icon `mic`): opens the recording panel; not shown in an empty project
  - then later: Stickers, Effects, Filters, Remove BG, Speed (there is no parent "Audio" tool: audio effects live in the sound clips' tool bar, P3-09)
  - Canvas and ratio are entered from the top-bar chip. Tools are left-aligned so each keeps its place as more arrive. Before launch a tool may sit one place to the left until the tool before it is built; users only ever see the final order.
  - Empty project (no clips): Add media is the only tool.
- **Clip mode (an item is selected):**
  - The same bar switches to that item's tools: a leading 48 dp Close clip tools button (`arrow_back`), a `hairline` divider, then the tools.
  - Delete sits among the first tools, visible without scrolling at 360 dp, and uses `danger` for its icon and label.
  - The switch is a 120 ms cross-fade. Full lists: `docs/ux/specs/P1-06-clip-edits-and-audio.md`; text items in `docs/ux/specs/P1-10-text.md` (Edit text · Style · Position · Delete · Split · Move here · Duplicate).
- **Reorder mode** (video editor): the bar shows Move earlier and Move later (Secondary buttons) and Done (Quiet button) in a row that wraps at large font sizes, on the same `surface` with the same `hairline` top border (P1-06 → Reorder bar).
- **Photo editor tools (final order, each added with its ticket; spec `docs/ux/specs/P2-01-photo-editor-shell.md`):** Formats (P2-02; or the board's separate format bar, P2-02 decides) · Text (P2-03) · Stickers (P2-03) · Add photo (P2-13) · **Layers** (P2-01, the only tool at first) · Draw (P2-05) · Adjust and Filters (P2-04) · Remove BG (P2-07) · Censor (P2-05) · Crop (P2-04). Before a tool exists the others sit one place to the left; users only ever see the final order. Never a disabled placeholder.
- **Photo editor, a layer selected:** the clip-mode pattern (Close layer tools, divider, tools): **Position · Opacity · Delete · Duplicate · Lock · Hide · Layers**, with each layer type's own tools in front (text: Edit text · Style · Position, P2-03). A locked layer's Lock slot reads **Unlock**, a hidden layer's Hide slot reads **Show**; the icon shows the layer's current state (closed lock, slashed eye), the label names the action. A layer whose file is missing starts with Delete.
- **Toggle tools (P4-10, `ToolBarItem.switchOn: Boolean?`):** `null` is a normal button. A non-null value makes the tool a switch: TalkBack says "<label>, switch, on/off" (`Role.Switch`, `ToggleableState`), the click label names the tap, and the visible label never changes (WCAG 2.5.3). The caller draws the on state with the active look (`primary` on `primary-subtle`). First user: Reverse. Use it only for per-clip on/off tools.
- **Reverse and Freeze frame (P4-10):** Reverse (switch) is in the main video clip bar and the video overlay bar; Freeze frame only in the main video clip bar, both after Speed (final order in P4-09). Absent on photo clips and on a freeze clip (its bar: Split, Delete, Crop, Fill or Fit, Position, Filters, Green screen, Mask, Keyframes, Transition, Duplicate, Reorder).
- **Meme sounds tool:** always `primary` icon and label, because it's meme-sound UI.
- **Sound clip tools** (P1-08, P3-09): Volume · Split · Delete · **Audio effects** (P3-09, icon `audio_effects`) · Move here · Duplicate. The same for meme sounds and audio clips (voiceover, imported, detached original audio); a video clip has none (Detach audio first). Icons `volume` (three rising bars, the tallest solid) and `move_here` (an arrow into the playhead bar).
- **Overlay clip tools** (P4-01b): video overlay Position · Opacity · Delete · Split · Volume · Layer order · Move here · Duplicate · Detach audio; photo overlay without Volume and Detach audio. P4-16 inserts Crop after Volume (after Split on a photo). No Replace. Layer order opens a panel with Bring forward and Send back (icon `layers`); a missing file starts with Delete.
- **Main clip tools:** Split · Volume (P1-09) · Delete · **Crop · Fill or Fit · Position (P4-16)** · Duplicate · Detach audio (P1-09) · Reorder · Replace (P1-16; photos have no Volume or Detach audio). The Fill or Fit tool is one toggle whose label and icon (`fill`, `fit`) name what the tap does. On a clip whose file is missing, Replace comes first, because it's the one tool that fixes it and the missing-file toast names it. Once fixed, the usual order returns. Icon `replace`: a solid clip between two curved arrows (DESIGN_SYSTEM → Iconography).
- **Phase 4 pro tools, final order (P4-04, P4-02b, P4-03b, P4-07):** video overlay Position · Opacity · Delete · **Green screen** · Split · Volume · Crop · **Blend · Mask · Filters · Keyframes** · Layer order · Move here · Duplicate · Detach audio (a photo overlay has no Volume or Detach audio); main video clip Split · Volume · Delete · Crop · Fill or Fit · Position · **Filters · Green screen · Mask · Keyframes** · Duplicate · Detach audio · Reorder · Replace; main photo clip the same without Volume and Detach audio; caption Edit text · Style · Position · Delete · **Keyframes** · Split · Move here · Duplicate; sound or audio clip Volume · Split · Delete · Audio effects · **Keyframes** · Move here · Duplicate. The video editor's main bar gains **Filters** (all main clips) between Effects and Remove BG. New icons `green_screen`, `mask`, `blend`, `keyframe`, `easing`; Filters reuses `adjust`. Tools that don't apply to an item are absent, never disabled.
- **Time, effect and transition tools (P4-06, P4-08, P4-09, P4-10; final orders, specs `docs/ux/specs/P4-06-video-effects.md`, `P4-08-transitions.md`, `P4-09-speed.md`, `P4-10-reverse-and-freeze.md`):** main video clip Split · Volume · Delete · **Speed · Freeze frame · Reverse** · Crop · Fill or Fit · Position · Filters · Green screen · Mask · Keyframes · **Transition** · Duplicate · Detach audio · Reorder · Replace (a main photo clip has none of Speed, Freeze frame, Reverse, Detach audio, Volume; Transition stays; a freeze clip is a photo clip without Replace); video overlay gains **Speed · Reverse** after Volume. Effect item (clip mode): **Intensity · Delete · Change effect · Split · Move here · Duplicate**. The main bar's **Effects** (after Stickers) opens the Effects sheet; its **Speed** (last) selects the video clip under the playhead and opens Speed. Reverse is a switch with the active look when on. New icons `effects`, `transition`, `speed`, `reverse`, `freeze`; Intensity reuses `adjust`, Change effect reuses `replace`.
- **Keyframe bar** (video editor, P4-02b): a mode that replaces the bar, like the reorder bar, while the timeline and stage stay live: a leading Close (`arrow_back`) and a `hairline` divider, then **Previous · Add keyframe or Remove keyframe · Next · Easing · Move here · Position · Opacity · Volume · Clear all** (Position, Opacity and Volume only where the item has them). Add keyframe is one tool whose label names what the tap does; on a keyframe it reads Remove keyframe and takes the active look (`primary` on `primary-subtle`). Spec `docs/ux/specs/P4-02b-keyframes.md`.
- **Active tool** (its panel or sheet is open): `primary` icon and label on a `primary-subtle` `radius-md` highlight, where it can be seen. In the video editor the Volume panel and the half-height Meme sounds sheet both cover the bar, so the look never shows there.
- **Other tools:** `text-secondary`. A tool that can't act right now keeps its look and explains on tap with a Toast. It never shows as a disabled placeholder.
- **Spoken names:** a tool's accessible name is its visible label, in every language (WCAG 2.2 SC 2.5.3 Label in Name, Level A). When the label needs more context, add it as the click label, which TalkBack reads as "Double-tap to …": Move here is named "Move here" and its click label is "Move to playhead" (P1-08 review). Never replace the name with different words.
- **Layout:**
  - `surface` bar, `toolbar-height`, `hairline` top border.
  - Items at least `tool-item-width` wide and at least `touch-target` tall; labels in `caption`. Two lines is the copy budget, not a line cap: labels are never cut.
  - **Every label keeps room for two lines** (P1-09 review), so a one-line label sits at the top of a two-line space. One line made a tool 58 dp tall and two lines 72 dp (`toolbar-height`). A bar holding one two-line label (English "Detach audio") then put every icon 7 dp higher than a bar without one, and switching between a photo clip's and a video clip's tools cross-faded two icon rows 7 dp apart. With the two-line room, the icon line never moves between bars at 100% font. In Compose: `minLines = 2` on the label.
  - At large font scales, items widen when a word can't fit, and labels may take more lines; the bar grows taller rather than cutting labels.
  - No outlines or shadows.
