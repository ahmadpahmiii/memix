# Slider

A labeled slider with a live value, for volume, pitch, intensity, opacity and every adjustment.

- **Provide:** label, range, step, current value and its formatted readout (`timecode` style).
- **Track:** 4px, filled part `primary`, rest `hairline`; **thumb:** 22px `selection` (white) disc, as in CapCut, so it's easy to see and grab.
- **Double-tap** the thumb to reset to the default value.
