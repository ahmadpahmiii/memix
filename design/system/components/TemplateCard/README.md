# TemplateCard

A 9:16 template thumbnail with its name and type badge, for Home and Templates grids. No use count until real usage data exists.

- **Provide:** a preview image or looping preview, the template name, its type (Green screen, Preset, Photo) and a short subtitle such as the slot count.
- **Layout:** `radius-lg` frame on `surface`, no outline or shadow; the badge sits bottom-left on a 70% black wash so it reads over any thumbnail.
- **Grids:** two columns on Templates, a horizontal row on Home, `space-3` gaps.
