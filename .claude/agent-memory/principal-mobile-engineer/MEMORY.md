# principal-mobile-engineer memory

Lessons for this project only, newest first. Keep under ~150 lines; prune stale items. Focus: API gotchas (with versions), performance baselines per device, recurring review findings, patterns that worked.

- 2026-10-08 · P1-01 · SQLDelight 2.4.1: no explicit transaction around a save. On SQLITE_FULL, SQLite rolls back by itself, SQLDelight's ROLLBACK in `finally` then throws "cannot rollback - no transaction is active", and that hides the disk-full error (seen with sqlite-jdbc; Android reports the same). Use one statement (`INSERT OR REPLACE` + subquery to keep columns). Android 10 = SQLite 3.22, so no UPSERT; keep the default 3.18 dialect.
- 2026-10-08 · P1-01 · SQLDelight: running `generate…Schema` and `verifySqlDelightMigration` in one Gradle invocation fails task validation (schema dir sits inside srcDirs); run them separately. Verify catches a .sq change without a .sqm (checked).
- 2026-10-08 · P1-01 · No Android SDK in cloud sessions: a scratchpad JVM harness (Kotlin JVM 2.4.20 + serialization + SQLDelight + sqlite-driver, srcDirs pointing at the repo's commonMain) compiles common code, runs codegen/verify and real round trips. Two JVM processes on one file stand in for force-stop. JDBC `PRAGMA max_page_count` is per connection (one per thread): pass it as a connection property.
- 2026-10-08 · P1-01 · Kotlin 2.4.20: `kotlin.uuid.Uuid` (since 2.4) and `kotlin.time.Clock`/`Instant` (since 2.3) need no opt-in; `import kotlinx.coroutines.IO` + `Dispatchers.IO` compiles in common code (coroutines 1.11.0). sqldelight.github.io is blocked here; read docs from raw.githubusercontent.com/sqldelight/sqldelight/<tag>/docs/.
- 2026-10-08 · P1-01 · Patterns: platform `SqlDriver` lives in `:composeApp` `databaseDriverModule` (expect/actual), `:core:data` stays commonMain. Repository logs exceptions at the boundary; decode errors log only the exception class (messages quote JSON with gallery URIs). `catch (e: CancellationException) { throw e }` before `catch (e: Exception)` around `withContext`.
- 2026-10-08 · P0 · AGP 9 keeps com.android.application out of KMP modules (the app is :androidApp). Compose 1.12: Modifier.dropShadow(shape, Shadow) exists; BackHandler is deprecated, use NavigationBackHandler (navigationevent 1.1.0). A sheet that holds focus must handle Key.Back itself. The phone's region comes from LocaleManager.systemLocales, not Locale.getDefault().
