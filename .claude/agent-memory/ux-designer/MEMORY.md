Lessons for this project only, newest first. Keep under ~150 lines; prune stale items. Focus: Design decisions and their reasons, patterns that worked or failed, recurring review issues, competitor insights.

- 2026-10-21 · P1-11 review (provisional, code + renders 180–197, stand-in picture, no real blur). Changes requested, all screen-reader: M1 SettingPill set only `expand`/`collapse` actions, so no open/closed state is spoken (add `stateDescription` "Expanded"/"Collapsed"); M2 OptionTile put the Fit/Fill hint in `stateDescription`, which replaces the spoken "selected" (my spec asked for it; hint now goes in the name after the label); M3 caption TalkBack nodes kept onClick + Style/Position actions under the Canvas panel, so panels could stack. Lessons:
  - **Never spec extra words as a state description on a selectable/checkable control.** Extra meaning goes in the name, after the visible label.
  - **Expanded/collapsed needs a spoken state, not just actions.** Every disclosure control gets state strings.
  - **When a mode disables touch gestures on an area, disable the same actions on its TalkBack nodes** (keep them readable). Check every semantics `onClick`/`customActions` against each mode that blocks the touch path.
  - **A selected item in a scrolling row must be scrolled into view** when its panel opens or undo changes it (Custom at the row's end was fully off screen at 200%/es/pt while its steppers showed).
  - **Inline pairs in a FlowRow item still squeeze:** make the pair itself a FlowRow. Measure the 200% fit from a render's 100% tile widths × 2.
  - Accepted: 720 px preview while Blur is on (sigma follows the preview output). The `blur` crosshair glyph reads weakly at `icon-small`; recheck on device, redraw at P2-12 if needed.
- 2026-10-21 · P1-10 review (provisional, code + renders 160–174 with a fake text renderer). Changes requested: M1 the stage `BoxWithConstraints` had no `clipToBounds`, so the caption frame drew over the top bar, transport row and entry bar (render 167). Lessons and decisions:
  - **Anything drawn from content bounds (frames, guides, hit/a11y rects) needs a clip at its region's edge.** Compose never clips by default. Check every overlay layer for a clip when its content can be bigger than the region (long captions, big scales, short stages while typing).
  - **Motion that plays under a panel/keyboard opening at the same moment is moot** (the 200 ms playhead scroll became a jump). Same rule as "covered states are moot".
  - **Horizontal rows in a padded panel: padding goes inside the scroll** (layout bleed + `horizontalScroll` + `padding`), else a hard cut 16 dp from the edge.
  - **Every stepper needs a spoken result for every button,** not just the ones with a readout (Move had none). Give the string in the spec.
  - **Draft-look constants still open at build (Teko factor) get a provisional token value and a deadline before the first build that creates real drafts** (internal testing), so no migration is needed.
  - Desktop renders that start in a mode (typing) skip state captured on entry (the "never bigger" cap); don't judge that from them.
  - Fixed DESIGN_SYSTEM States: selected segment is white (SegmentedChoice), `surface-raised` never marks selection.
- 2026-10-21 · P1-12 final + P1-13 spec. Decisions and reasons:
  - **Capability conflicts: the tapped option wins,** the other setting steps down with a toast that says so (replaced "explain and keep": it forced a read-and-two-taps dance). Fully impossible options explain and keep the selection; "shape" copy when the same resolution works at 16:9 (custom 2.39:1 4K needs codec Level 6), "phone" copy otherwise. A remembered setting that's impossible here gets a visible "lowered" notice, never a silent change.
  - **Estimate copy "Up to 18 MB":** VBR undershoots on stills (most memes), so the estimate is an upper bound (+5% margin); "about" would be wrong low, "up to about" double-hedges.
  - **Share (owner 21 Oct) is secondary,** in the share row's future slot; Done stays the one blue, as after P5-05, so the primary doesn't move twice.
  - **Notification permission:** asked once at the first Export video, after the service starts; never again. Leave-the-app line made true with or without permission ("…keeps exporting and saves to your gallery"), so no variant. No notification can follow a process death; use a next-start persistent toast.
  - **`missing_media` defined** as an input that vanishes or becomes unreadable mid-export; missing at start exports black with no event. Added `decoder`, `system_stopped`; Task Manager stop = `export_cancel` at next start with the last saved percent.
  - **Watermark:** content constants in `tokens.json` → `watermark` (not drafts, so no schema bump): Anton, 4% of short side, 3% margin to the ink box on both edges, white 80% + unoffset soft shadow, export only, not in preview. Sheet row is a non-interactive container until P5-02 adds Remove.
  - **Finding for the owner:** TikTok's top UI covers ~130–260 px of 1080×1920 (third-party tools citing TikTok's ad template), so the top-left 3% mark may sit under TikTok's LIVE icon. Recommended a private test post at phase-end QA before moving it.
  - **Lesson:** when a decision log says "the designer updates spec X's analytics table", do it in the same pass as marking questions answered (P1-11 `value`).

- 2026-10-20 · P1-09 review (provisional, code + renders 110–128). - 2026-10-19 · P1-16 review (provisional, code + renders 85–99). Approved with polish, no must-fix. Decisions and lessons:
  - **A control under another control's touch target hides; it doesn't shift.** Add media tile hides while the selected main clip ends < `touch-target` before the video end (always the last clip; also the clip before a narrow last clip when zoomed out). Shifting = a target jumping right after a selection tap (mis-taps) and a gap that breaks proximity. Check every overlay against handle targets at zoomed-out scales too.
  - **Sheet focus trap must end when the sheet starts leaving.** `onExit` cancel during the 200 ms exit swallows focus-return requests when focus sat on a sheet button. Rule now in the Sheet README. Compose: an unattached FocusRequester's requestFocus just warns and returns false (no crash); clickables take no focus in touch mode, so TalkBack focus return is always a device check.
  - **Uniform scale animations on wide timeline items sweep over neighbors.** Bonk = height ×1.12, width grows by the same dp. Check any scale motion on long items.
  - **Icon gaps:** measure the gap between solid parts in the vector paths; ≥ 1.4px or it fuses at 2×. Arrowheads are always solid and aren't the core.
  - **Defensive states with an instruction need room at 200% Hindi:** a message inside a 9:16 frame gets ~155 dp; use the stage.
  - **Copy consistency checks:** a toast's term for a state must match the state's spoken word (id "dilepas" vs "dipisahkan"); two adjacent tools mustn't share a verb (hi "बदलें" vs "क्रम बदलें").
  - Renders 94b etc. are state-only (selection/toasts forced); don't read model state from them.
- 2026-10-19 · P1-08 review (provisional, code + renders 70–84). Changes requested: M1 Move here spoken "Move to playhead" fails WCAG 2.5.3 (my spec's error); M2 timeline + tool bar under the ToolPanel stayed in the a11y tree/focus (2.4.11); M3 pill label cut at 200% es/pt (computed ~372 dp vs 360). Lessons:
  - **Never replace a visible label with a different spoken name.** Extra context goes in the click label (TalkBack "Double-tap to …"); custom actions with no visible label may say anything.
  - **Anything drawn over other UI must also hide it from TalkBack and focus** (`clearAndSetSemantics {}` + focus group with `onEnter` cancel). Sheets still have this gap everywhere (F1).
  - **Every single-line label in chrome: compute es/pt at 200% against 360 dp** (label 13 sp ≈ 7.4 dp/char at 100%). The harness renders Hindi only; Hindi is short, es/pt are long.
  - **Check pressed state and true target size on every custom clickable** (padding before `clickable` shrinks the target; `indication = null` with no fill change = no feedback).
  - **Docs drift between tokens.json usage text and component READMEs:** `primary-subtle` "backs the playing row" vs README/board `surface`. Rule settled: playing row = one value step above its container; `primary-subtle` never fills a row; `primary-subtle` fills press to `surface-raised`.
  - **Covered UI states (active tool under a sheet/panel) are moot:** don't spec looks nobody can see.
  - **Slider: keyboard/TalkBack steps must land on the grid**, or the default is unreachable without a pointer.
  - **Moving markers vs new content:** a fixed marker (the pill) hides during a lane slide instead of passing over a landing item.
  - Semantics dump prints only content descriptions; ask for text nodes too.
- 2026-10-13 · P1-06 review (provisional, code + Skia renders 40–63 in `scratchpad/render-p1-05/out`). Changes requested: M1 reorder taps and grabs used x only, so washed areas moved clips; M2 the moving tile left the screen in tap mode (my spec had no keep-in-view rule). Lessons:
  - **In any modal state, check hit-tests use both axes** (gesture code that passes only `position.x`).
  - **Any mode that moves things by buttons needs a keep-in-view rule.**
  - **Android reduce motion = animator scale 0, and Compose ends every animation on the next frame at 0** (MotionDurationScale). The "120 ms fade" cells are instant on Android and real only on iOS. Don't make reduce-motion morph-vs-fade a must-fix on Android.
  - **No soft shadow on small floating chips over the timeline:** invisible on `canvas`, dirt on clips and handles. The value bubble dropped `shadow-float`.
  - **`IntrinsicSize.Min` + `maxLines` cuts multi-word labels at 200%.** Labels get no line cap; two lines is a budget.
  - **The token mirror drifted** (`design/system/tokens.json` missed all of P1-10). Compare both files' top-level line numbers every time.
  - **A toast that names a tool must use the tool's exact label in every language** (hi डिलीट vs हटाएं).
  - Renders 50–57 were state-only (no selection). Ask for the semantics dump to see what's really selected.

- 2026-10-10 · P1-05 review (provisional, from code + the engineer's Skia desktop renders, `scratchpad/render-p1-05/out`; ask for these again, they're a good stand-in when there's no emulator). Pass with fixes. Lessons:
  - **Check every visual-only state for a spoken twin.** "File missing" was drawn but not spoken (M1), and the P1-04 toast told TalkBack users to delete a clip they couldn't find. My spec missed it.
  - **Compose drops off-screen semantics nodes**, so "all items from the model" can't work for a virtualized canvas. Use the lazy pattern (on-screen nodes plus a scroll action). Per-row scroll has an order flaw: lane 2 starts where lane 1 ended. The fallback is one scroll node for all rows, read screen by screen.
  - **Ruler ladder needs rungs up to 1 h** (15 min, 30 min, 1 h, then whole hours): an hour at the whole-video zoom is 0.05 dp per second. Check every scale table at the extreme zoom.
  - **Fixed playhead over ruler labels is accepted:** the timecode carries the exact time.
  - **Every long-press that triggers something gets a LongPress haptic.**
  - **Response-time rule** for the P1-06 preview catching up: nothing up to 1 s, then a quiet static status (Nielsen limits; no spinner, MOTION 2).
  - **Mirror file:** `design/system/tokens.json` mirrors `design/tokens.json`; update both. Hindi display is now 60/44 (Teko's 1.433 em).
- 2026-10-09 · P1-10 text spec (`docs/ux/specs/P1-10-text.md`):
  - **Caption fonts:** Classic `anton` (+ Teko Bold for Devanagari clusters), Modern `poppins` (Bold 152 KB), Bubbly `baloo2` (ExtraBold static 348 KB, from yanone/Baloo2-Variable since google/fonts only has the 667 KB variable), Handwritten `kalam` (Bold 450 KB), Serif `rozha` (315 KB). Runners-up: Yatra One (brush, regional), Bangers (no Devanagari). Ids are saved forever.
  - **No schema bump:** base size 8% of the canvas short side, wrap 90%, stroke size ÷ 12 with round joins, center alignment and case-as-typed are fixed rules in `tokens.json` → `caption`. Changing a rule later needs a bump plus a compensating migration. Shadow and background box are PRD v1 features with no ticket: owner decision, recommended a new P2 ticket after P2-03.
  - **Patterns:** one shared caption renderer (preview overlay, gesture stand-in, export, photo editor); the stage shrinks above the keyboard while typing but never grows; every exit from typing commits; a stage tap outside text always toggles play (no tap-to-deselect, consistent with P1-04/06); two fingers anywhere on the stage transform the selected text, because preview captions are tiny; the Position panel (stepper buttons, no sliders) is the WCAG 2.5.1/2.5.7 route; white selection over content gets a 1px `on-primary` edge (4.3:1 or more on any color).

- 2026-10-08 · P1-04/05/06 (+P1-07/08/09) · Video editor core specs:
