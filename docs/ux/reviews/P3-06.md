# Design review: P3-06 Favorites and recently used

Reviewed 11 Nov 2026 against `docs/ux/specs/P3-02-sounds-library.md` (Favorites tab, Recently used, heart) and the P3-02 review notes. Evidence: the 10 desktop renders in `docs/ux/reviews/P3-06/`, the handoff, and the code in `feature/sounds/` and `SoundRow.kt`. No device, TalkBack or haptic run exists yet (the handoff says so); those items are marked "code only" and go to phase-end QA.

## Verdict: Pass with polish

No must-fixes. Five small fixes below; none blocks the commit.

## Builder decisions

| Decision | Verdict |
| --- | --- |

## Checks

- **Tokens only: pass for this ticket.** Heading uses `label`, `text-secondary`, `space-6` above (not first), `space-2` below; hint is `body` `text-secondary`; hearts `text-secondary` / `text`; playing band `surface` on `canvas`. No hex or dp in `feature/sounds`. One raw value remains in `SoundRow.kt`: `36.dp` for the add block (from P1-08, hidden until P3-15). Fixed on my side: new token `sound-add-size` (36px). See Token changes.
- **Every state:** both sections, un-hearted row staying, hint (recents, no favorites), favorites only (heading becomes first, no top gap), empty (heart, title, body, "Browse trending"), search with a match in both sections, search with no match ("No sounds for "zzqq"", Clear search), Trending hearts. All match the spec table. Not rendered: a favorite whose sound left the catalog (the "No longer available" row is P3-04, the handoff lists the inner-join limit; fine until then), loading and offline on Favorites (local list, so none needed).
- **Copy and budgets** (budgets: recent 24, favorites section 20, favorites tab 14, empty body 60, action strings 40):

  All within budget; `es` and `hi` renders show no clipping or wrapping of the headings. The machine drafts read naturally. Two polish points: `sounds_empty_favorites_body` in hi says "यहाँ ... सेव रहेगा", while the other hi strings use the "ं" spelling ("आज़माएं", "हटाएं"); use "यहां" for consistency. "Hearts" in es/pt/id keep the word for the icon ("corazón", "coração", "hati"), good because the user sees a heart.
- **200% font (hi render):** headings, names, two-line meta ("Royalty-free" wraps, never cut), and 48 dp hearts all hold; Devanagari line height is not clipped on names such as "उदास ट्रॉम्बोन" or on the heading. The tab strip scrolls and keeps the selected tab visible. Pass.
- **TalkBack (code only):** heart is `toggleable` with `Role.Switch` and "Favorite {name}": speaks "Favorite Bruh, switch, on". The name block merges to "{name}, {meta}" with a custom action "Add to favorites" / "Remove from favorites", so favoriting never depends on the small target. Section titles are `heading()`. Reading order disc, name block, heart is right. Pass. Needs one TalkBack pass on a phone at phase-end QA.
- **Motion and haptics:** the heart swaps at once, no animation. The spec's 120 ms is below what the eye reads as a transition, so this is acceptable and identical under reduce-motion. Tab cross-fade belongs to P3-02. SegmentTick on on, none on off, per spec (code only).
- **Selection and blue:** hearts are white (`text`), never blue; the only blue on the screen is the sound discs, as the README requires. No v1 colors.

## Polish (fix in this commit if cheap, otherwise in P3-15)

1. **First heading touches the tab underline.** In every render "Recently used" sits right under the tab underline, with only the heading's own inset; the gap looks tighter than between sections, and at 200% hi the heading nearly touches it. Spec line "space-6 above (not on the first)" is read literally by the build. Add `space-2` above the first heading (I'm updating the intent: the first heading gets `space-2`, later ones `space-6`). Spec: P3-02 Tab contents, Favorites.
2. **Hint spacing:** the hint under "Favorites" (`favorites-hint.png`) has a larger gap above the heading than below, fine, but the hint's text is `body` at full width and wraps long in es/pt at 200%. Verify with a 200% es render at phase-end QA; no change needed now.
3. **hi spelling** "यहाँ" to "यहां" (above).
4. **Duplicate playing state** (`favorites.png`): "Bruh" plays in both sections at once, two pause discs and two bands. Correct (one sound), now documented in the SoundRow README; QA should not file it as a bug.
5. **P3-03 must keep the TalkBack action.** The name block is merged here with no click. When P3-03 turns it into the details button, keep `customActions` (and the merge) on it. Noted in the SoundRow README.
