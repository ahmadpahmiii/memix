The three tabs follow the spec: tokens only, no outline, shadow or gradient, no blue action, white selection on the chosen voice tile, one blue dot per active tab. Five languages are present and match the spec text. No must-fixes. Polish items below can ride with 09c or QA fixes.

## Layout
At 256 dp the harness shows only one slider and the start of the next, as in 09a. Real 360 x 800 has 158 dp under the tabs. Bass needs 2 x 68 = 136 (fits). Echo needs a slider 68 + Echo length label and segments about 76 = 144 (fits, 14 dp spare). **QA check on a real 360 x 800 at 100% font:** Bass shows both sliders and Echo shows both controls without scrolling; if not, report the panel height and I accept scrolling. 640 and 200% scroll by the ToolPanel rule.

## Answers to the builder's decisions
1. **Tab order Voice, Tone, Bass, Echo, Fades; Voice first on a fresh visit:** accepted, it is the spec's final order and "first tab". Voice is the most meme-like control and it is one tap with no slider. Last-used tab is not remembered across opens, fine. A fresh visit while only Tone is set still opens on Voice; the dots show where the effect is.
2. **Voice tiles use P3-11's OptionTile label layout:** accepted and as specced. Role is RadioButton via `selectable` inside a selectable group; the tile's spoken name is its label, so TalkBack says "Chipmunk, radio button, selected" and the group is named "Voice" (WCAG 2.5.3 met). Position "n of 6" comes from `collectionItemInfo`. Tapping the selected tile does nothing, as specced.
3. **Bass and Distortion live while dragging, Echo, length and voice after release:** accepted. It continues the 09a rule (live where cheap, on release where the length or shape changes). QA bar stays: release to new sound under 1 s with no silent gap; if over, the "Preparing audio" status becomes required for Echo and Voice.
4. **Voice hint and Echo length below the fold at 360 x 640:** accepted (floor size, scrolling is the designed fallback). Both controls are reachable by TalkBack focus (it scrolls to focus).
5. **Level sliders snap to 0 within 3%:** accepted. 3% is under the 10% step so every step remains reachable, and one SegmentTick lands at 0 (spec: "snap to the default"). Same idea as Pitch's half semitone.
6. **Echo tail past the clip end; a sound inside the tail moves lane. Surprising?** Yes, a little: the tail is not drawn, so a sound can hop to another lane with no visible overlap, which is the one thing the user cannot explain. **Decision (revised 16 Nov by the coordinator, after code review): no hint and no toast.** The tail lane move is plan-only (engine lane packing; the project and timeline never change), so a "moved to another track" toast would describe nothing the user can see. A set Fade out means no tail, so no lane is reserved. My earlier "reuse `fx_moved_lane_toast`" suggestion is withdrawn; the toast stays for Speed only. A faint drawn tail on the selected clip remains a possible later proposal (needs a token). Spec tail line updated. The engineer's "confirm the toast fires" request no longer applies.
7. **Voice numbers are starting values:** accepted, with a rule for the ear check: judge by whether the preset is recognisable in a second on a phone speaker, not on headphones; Chipmunk +7 and Giant -6 are within the common range for such presets (Assumption, my reasoning, not a studied source). Record the final numbers in the reference notes and tell me if a preset needs another name (a Robot that sounds like a megaphone should be renamed or retuned, not left).

## Polish (not blocking)
1. **Tab row clips at the 16 dp padding, not at the screen edge.** `panel-es-voice` shows "Fundidos" cut at the right padding; `panel-hi-200-echo` shows the first letter of आवाज़ cut at the left. A scroll row of tabs should bleed to the panel edge, like the Voice tiles do, so the cut reads as "more here" and not as a clipped word. Fix: let the tab row's scroll area run edge to edge with content padding 16 dp (the pattern the tile row already uses). Spec Layout: "Tabs".
2. **"Echo length" label is `text-secondary` and the sliders' labels are `text`.** The label is the ChoiceRow heading; it reads as a lesser control next to "Echo". Use `text` `bodyStrong` like the slider labels for visual parity in this panel (Layout consistency).
3. **Panel region in Voice at 640:** hint's last line is clipped at the bottom edge. Scrolls, but add the pinned/scrolling bottom padding (space4) so the hint can come fully into view when scrolled. By the ToolPanel README, scrolling content ends with `space4`.
4. Reset sits close to the title in es ("Efectos de audio" ends about 12 dp before "Restablecer"). Passes; keep an eye at 130% font, where Reset wraps (spec behavior as P2-04).
