## Checks

**Tokens only: pass.** `MakeVideoRow` uses `MemixColors.canvas`, `MemixSpacing.space1`, `MemixMotion.durationSheet`, `MemixIcons.Video` and the DS `Button`. No hex, dp, sp or font literal in the two files; no v1 colors. Busy look is the documented busy Button (`surface-raised`, `text-secondary` 5.7:1), seen in `04-working`.

**Spec states: all present.** Default (01), layer selected (02), panels collapse the row (03), working (04), busy and empty toasts (05, 08), both failure toasts (06), arrival with sounds sheet, note, no note the second time, Hindi/Spanish/Portuguese/Indonesian. Missing from the evidence, so phone checks: missing picture file, interrupted conversion (no half draft; harness covers it).

The es and pt failure toasts run 4 to 5 over; toasts wrap, so acceptable. Tone is right in all five: verb first, "you/your", Indonesian and Spanish use the informal form like the rest of the app. Hindi note: "लेयर" and "टेक्स्ट" are the app's usual loanwords, consistent.

**200% font: pass.** Hindi, Spanish, Portuguese at 200% (07) keep the button whole and the row grows; Hindi 200% fits on one line at 360. The Hindi note at 200% (video-note-hindi-200) wraps to three lines plus Got it and is not cut. It covers most of the preview while it shows; it is dismissible and persistent by design, so acceptable.

**TalkBack: pass with one phone check.** The button's name is its visible label (the Button component sets the button role; the icon is decorative). "Making video…" is a polite live region and the busy Button is not clickable, so TalkBack reads it as unavailable, which is correct. The input block swallows touches but explore-by-touch could still land on tools beneath it; the busy rule in the view model (`start()` returns early) makes any activation a no-op, so this is safe (C-3: confirm no tool fires under TalkBack while working). Toasts reuse the polite toast channel.

**Motion and reduce motion: pass.** Row enter and exit use `snap()` under reduce motion, as the spec says; `FrameRefit` also snaps. Normal motion is 200 ms tween on both, with no exit animation for the working state (correct: MOTION 2).

**One blue action: pass.** The photo editor keeps Export as its only blue; the video-editor arrival shows the sheet's blue adds.

## Polish (small fixes, not blocking)

- **P-1 Drafts cover.** The video draft's cover lacks the captions, so on Drafts the two drafts of one meme look different and the video one looks text-less. For a caption-led meme this undersells the result. Request to the principal engineer (a P1-03 cover-reader follow-up, not in P2-10): draw the lifted text on the cover, or until then log it for the Phase 2 gate. PM item, not a design change.
- **P-2 Budgets.** Raise `make_video_title` to 30 characters in the spec's copy table; keep wrapping.
- **P-3 Spec amended** (done): label style and lanes.
- **P-4 Fail toast copy.** If space on es/pt toasts is a problem on 360 dp phones at 200%, shorten to "No se pudo crear el video. Inténtalo de nuevo." Only if the phone check shows an ugly three-line toast.
