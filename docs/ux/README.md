# UX

Owned by the UX designer.

- `research/`: desk research, competitor teardowns, heuristic evaluations
- `specs/`: one screen spec per UI ticket, written before the build
- `reviews/`: design verdicts on built screens
- `CHANGELOG.md`: design-system changes (to sync back to the claude.ai design canvas)

The look and tokens live in `docs/DESIGN_SYSTEM.md` and `design/tokens.json`.
