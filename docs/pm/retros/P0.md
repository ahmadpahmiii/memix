## 1. What went well (keep doing)

- **Check-in before generating files.** The kickoff's "show me modules, versions and task names" caught two doc gaps before any code: AGP 9 no longer allows the Android app inside a KMP module, and Compose Multiplatform was at 1.12.1, not 1.11.
- **Versions from official sources** (GitHub releases, Maven Central, Google Maven), not memory. No pre-releases slipped in.
- **Click-throughs found real bugs before merge:** a sheet that Escape couldn't close and Back that stopped working once the sheet held focus (P0-04); a region that reset to Global when the user picked an app language (found while planning P0-09).
- **The design filter paid off:** board sample content (template use counts, trending rows, a false gallery-permission line) never shipped as if it were real; the Home void was caught by the delivery check and turned into a composition.
- **Credentials:** an inventory, a complete `.gitignore` and a secret check (pre-commit and CI) landed before any credential was committed. The check exists because Android Studio had staged `google-services.json`.
- **Checked before writing:** the Supabase URL first given was another app's project; nothing was written there, and Memix got its own project.

## 3. Proposed changes

### 1. Fix the stale module names (cause B)
- `.claude/skills/qa-verification/SKILL.md` §2: `adb install -r composeApp/build/outputs/apk/debug/composeApp-debug.apk` → `./gradlew :androidApp:installDebug   # or: adb install -r androidApp/build/outputs/apk/debug/androidApp-debug.apk`
- `.claude/skills/play-release/SKILL.md` step 2: `./gradlew :composeApp:bundleRelease` → `./gradlew :androidApp:bundleRelease`
- `.claude/agents/principal-mobile-engineer.md`: `- All app code: \`:composeApp\`,` → `- All app code: \`:androidApp\`, \`:composeApp\`,`
- `CLAUDE.md`: `When behavior changes, update the doc in the same ticket commit.` → `When behavior, a module or a command changes, update the docs in the same ticket commit, including any skill or agent file that names it (grep \`.claude/\` for the old name).`
- Effect: QA and release commands work. Cost: 4 one-line edits.
- [ ] Approved by owner

### 2. Make adb checks reliable (cause C)
- `.claude/skills/qa-verification/SKILL.md` §3, after "Screenshot only the states you check; look at each one before moving on." add: `uiautomator lags the screen: after a tap or launch, wait about 1.5 s and dump twice before judging. Selected and checked states sit on the clickable parent node, not the text node. When a dump and the screen disagree, the screenshot wins.`
- Effect: no false FAILs, fewer re-runs (token cost). Cost: 3 lines.
- [ ] Approved by owner

### 3. Add a keyboard pass (cause D)
- `.claude/skills/qa-verification/SKILL.md` §4, append to the accessibility list: `keyboard: \`adb shell input keyevent KEYCODE_TAB\` through each new screen (screenshot the focus ring), \`KEYCODE_ENTER\` activates, \`KEYCODE_ESCAPE\` and \`KEYCODE_BACK\` close sheets and dialogs`
- `.claude/agents/principal-mobile-engineer.md` step 6, after "walk through the ticket's "Done when" yourself": add `, including one keyboard pass (Tab, Enter, Escape) on new screens`
- Effect: focus and dismissal bugs surface during the ticket, not at phase end. Cost: about 2 minutes per UI ticket.
- [ ] Approved by owner

### 4. Document the slow and stuck builds (cause E)
- `CLAUDE.md` → Commands, after the AGP 9 paragraph, add: `The first iOS link after adding a library takes up to 15 minutes while Kotlin/Native builds its caches; later links take under a minute. After the JDK changes, or on a "spawn helper" error, run \`./gradlew --stop\`.`
- Effect: no one waits on or debugs normal behavior. Cost: 2 lines.
- [ ] Approved by owner

### 5. Confirm the Supabase project before writing (cause F)
- `.claude/agents/backend-engineer.md` → Standards, first bullet: `- **Right project.** Before any write, confirm the project ref is Memix's (\`drnhpnixnewqjfmrchrr\`, see \`docs/CREDENTIALS.md\`) with \`get_project\` and \`list_tables\`. Never change a project that holds another app's data. Checks that need test rows run in a rolled-back transaction or clean up in the same session.`
- Effect: no cross-app damage. Cost: 1 bullet.
- [ ] Approved by owner

### 6. Rule for a skipped QA pass (cause G)
- `.claude/skills/ticket-workflow/SKILL.md` → End of phase, step 2, append: `If the owner skips the pass, the phase report says so, verdicts rest on the hand checks, and the next phase's test plan also covers the skipped phase's tickets.`
- Effect: Phase 0 still gets one QA pass (inside Phase 1's). Cost: P1's QA pass grows by 9 tickets, most of them quick.
- [ ] Approved by owner
